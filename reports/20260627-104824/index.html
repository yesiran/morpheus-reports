AMV 查无此物，但内核值得长押

你问的是：帮我研究一下李继刚说的 AMV 到底是什么，详细研究，全网去搜它相关的内容。——你真正在赌的，是这套提示词哲学该不该信、能不能上手、值不值得长期押。

总判断

“AMV”是个误传的壳，李继刚本人从没造过这个词；壳底下那台真机器，是他整套“提示词不是教模型、而是唤醒模型”的世界观。它偏真洞见、不是换皮：术会随模型变强而贬值，道会随模型变强而增值——而它的道，恰好是你做京小贝、搭 Morpheus 的看家本事换了个名字。所以：下注它的内核，把它的招式当耗材。

1

那“AMV”到底是怎么来的？

带回的判断

AMV = 查无此物。最可能是李继刚“三个世界（原子 / 比特 / 向量）”框架，在口耳相传、语音转写里被串成的误记。证据强度：中高。

如果他没说过 AMV，你怎么会“听说”他说过？先看一个出卖真伪的细节：一个真实存在的概念，搜它会返回“窄而一致”的语料；而“AMV”一搜，返回的是一堆毫不相干的东西——动漫音乐视频、一种视频格式、制药业的分析方法验证、装甲车、甚至一家法国保险公司。这种四处发散、没有一条挂得上提示词的反应，正是“这个词在这个语境里根本没语料”的典型信号。不是冷门，是不存在。

那真身是什么？最贴的一个，藏在他 2026 年 3 月跟孟岩的长播客《E45 孟岩对话李继刚：人何以自处》里。他反复讲：我们同时活在三个世界——原子世界（身体所在的物理现实，稀缺的是“在场”）、比特世界（互联网，稀缺的是“注意力”）、向量世界（AI 世界，万物被压成高维坐标，连时间都被抹平）。这三个词的英文首字母是 A-B-V：头尾的 A 和 V 跟“AMV”严丝合缝，只有中间那个“比特 / Bit”被记成了 M。而 M 的来源也有着落——他另有一套常讲的“效果三要素 = 模型（Model）/ 任务 / 提示词”，听的人极可能把“模型 Model”的 M，和“三个世界”串了台。

我们同时活在三个世界里：原子世界、比特世界、向量世界。 播客《E45 孟岩对话李继刚》2026-03-03 · 官方逐字稿（全文出现 Vector、Model，未出现 AMV 与 ABV）
反面 / 风险

这是本案最大的软环：“AMV = 三个世界（ABV）的误记”是中高置信推断，不是李继刚本人确认。唯一没封死的口子——他即刻 / X 的原始帖子流，本次环境抓不到（登录墙 + 本机浏览器桥未连），无法 100% 排除他在某条没被索引 / 已删的单帖里临场手写过 AMV。你若手上有原始截图 / 链接，给我，我能一步钉死或证伪。

2

剥开壳，它是台什么机器？

带回的判断

它的本质是一套底层机制解释，不是可操作技法、也不是一次思想转向。它瞄准的卡点是“写得对却不照做”——病根是意图没压清、点错了星，不是字数不够。

把术语外壳剥掉，第一个该问：这是“一个写法 / 技法”，还是“一套解释”？技法是螺丝刀（告诉你第一行怎么落笔），解释是图纸（告诉你为什么这么拧会松）。答案是：它是图纸，不是螺丝刀。李继刚整套东西，核心不是“教你怎么写提示词”，而是回答一个更底层的问题——为什么一句话能在模型里炸开成一整套行为？

他的机器图纸有三件（全有原话坐实）：表达三元——本意 → 文意 → 解意，你心里的想法是本意，写成的符号是文意，模型读成的是解意，任何一环错位就是误解源头；效果三因素——模型 > 任务 > 提示词，提示词只排第三，被你天天盯着抠只因它是三样里唯一你能直接动手调的那环；以及那个最有名的画面——潜空间里“点亮星星”：屋子是向量空间，星星是 embedding 之后的词或概念，喊星星的名字就能把它点亮，连成星座模型就懂了。拼起来就是他跟所有人最不一样的那一刀：好提示词不是“教”模型做事，而是“唤醒”模型。

那它瞄准的卡点，就是你我都撞过的那堵墙：“我明明写得清清楚楚、明明很对，模型却不照做、跑偏。”他的诊断反直觉——病根通常不在“指令下得不够细”，而在两处：① 你自己的本意本来就模糊；② 你以为在“教”模型（往里塞越来越多的字），可机制上你只是在屋子里点星星，塞得越多越乱，反而点不亮你要的那个星座。

3

对你这 prompt 老手，它新在哪？

带回的判断

偏真洞见的中间态，不是纯换皮。真实增量 = 把操作对象从“描述任务”挪到“操作模型潜空间里的概念坐标”，方向从加法翻成减法；虚的那半是用诗化比喻冒充操作步骤。

这一刀该最狠，因为你是内行——最该攻的恰恰是你太顺手的那套默认框架（结构化、角色设定、给例子、思维链）。让红队默认怀疑它是包装，逼它拿出“老框架解释不了、它能”的地方，拿不出就判换皮。结论是：他换了“操作对象”。

主流框架（CO-STAR / RTF / CRISPE / CoT）操作的是“我对任务的描述”——把背景切成栏位填进去；李继刚操作的是模型潜空间里已有的概念坐标——选一个能点亮一整条脉络的“本质词”。前者在黑箱外面排输入，他在赌黑箱内部有结构、可定位，这是真增量。核心动作也方向相反：主流是加法（背景写越全越好），他是减法（压到只剩那个本质词）。代价是他的退步面：抓手弱、难复制。还有一条反证——他从不用英文三字母给东西命名，全是汉字三字诀（信 / 达 / 雅、本意 / 文意 / 解意、译境、思想精炼师），“AMV”在风格上就不像他。

凡他给了“换个操作对象”的具体动作（去操作潜空间、而非描述任务），算真增量；凡他只给了一个更美的比喻（“点亮星星”“共振”“道”）而没告诉你下一步该写什么，算包装。 本案红队压测 · 判别口诀
反面 / 风险

它的退步面很实：可操作性低、吃天赋、几乎没法教——他自己也只能说“多读多思，各自悟道”。所以别指望靠它出一套能交给团队照抄的模板；玄的那半（点星星 / 共振 / 道）是对机制的诗化描述，不是可照做的步骤，最容易“把真洞见当玄学错过”，也最容易“把营销当洞见误信”。

4

这东西，能上你的手吗？

带回的判断

部分可借鉴——减法刀法可直接上手改你的 skill / 京小贝提示词；但“点星星 / 共振 / Lisp 美学”是心法不是方法。且生产级强领域不能照搬极简：减冗余指令，保私有示范。

把这套切成两半。能直接照做的动作（真能改一行字）：动手前先逼问“本意”——我到底想让模型变成谁、产出什么质感；用“定义”别用“描述”——能用一个一锤定音的身份词框死的，别写一长串行为说明，模型对定义词的解压远大于对描述句的；做减法删冗余——每加一条规则前先问“这是不是在教模型它本来就会的事（理解情绪、说人话、分点）”，是就删；找“本质词”当杠杆，把啰嗦要求压成一个能一词点亮一片的核心词；以及认清提示词只排第三，先确认模型选对、任务切对。

而没法照做的空话是另一半：“点亮星星 / 在潜空间点星座”是好用的心智图景，帮你理解为什么定义词强，但不告诉你该写哪个词；“唤醒 / 共振 / 道”方向对，但“怎么算唤醒成功”无法验证；“汉字三字诀美学 / Lisp 风格写 prompt”是他的个人品味和表达载体，不是效果来源，照搬只会得到一个“像他、但不像京小贝”的东西。

用他的减法刀，砍掉“教模型它本来就会的事”的废指令；但保留、甚至加厚你的私有示范。 本案落地结论 · 京小贝 / Morpheus skill
反面 / 风险

专门给老手挖的反向陷阱：别因为这套漂亮就整个倒向李继刚的极简风。他的活计（汉语新解、译境）是通用创意，点的星星是模型预训练里现成就有的，越压越灵；而京小贝是生产级 + 强私有领域，护城河恰恰在模型不自带的东西——京东金融的回复口味、合规红线、领域常识。这部分潜空间里没有现成的星星，只能靠你灌示范（“得其真意忘其言语”那几个案例），删不得。

5

该不该长期押？

带回的判断

在“模型变强”大趋势下，这套哲学是分层资产——术贬值、道增值，而它重心压在道。对你：长期下注它的内核，轻度跟进它的招式。它不是噪音，恰恰是少数“模型越强越值钱”的能力之一。

把它劈成两层，命运正好相反。术（技巧层）——具体话术、模板、咒语、“扮演专家”那类花活——模型变强后贬值：连 Anthropic 官方都说“模型越强，越要少规定”，“let’s think step by step”这类老咒语在 2026 前沿模型上已从有用变没用甚至有害，模型还会自己写提示词（meta-prompting）。道（认知 / 对齐层）——把脑子里那团模糊“本意”压成精准符号、对齐给一个智能体的能力——则增值：Karpathy 说“理解你要造什么、为什么造，是一种不可压缩的人类技能”，intent specification 是新的编程。

而李继刚的重心明明白白压在道上：他的“本意 → 文意 → 解意”讲的根本不是话术，是“把人脑海里的想法精准交给模型理解”，这跟 Karpathy 的 intent specification 是同一件事，只是一个用中文哲学讲、一个用工程黑话讲。更狠的是他早就预判了模型会变强（他叫“X 轴下移”），亲手把价值的钉子，从“提示词技巧”钉到了“人的认知边界”上。落到你身上，用段永平那只手算账：模板 / 咒语当易耗品，“本意 / 文意 / 解意 + 唤醒而非教导 + 减法不是加法”当长期资产——会用模型的人不稀缺，能把自己意图压清楚的人才稀缺。这跟你本业是同一条护城河（把模糊业务意图压成能被团队精确执行的 spec），下注它 = 给已有护城河加复利；写公众号写道别写术；沉进 Morpheus——它的内核（目的考古、把问题压到本质、唤醒 worker 而非教导）和李继刚的内核同构，把“本意 → 文意 → 解意”作为问题转化层的显式心法写进去，是最高杠杆的下注方式。

反面 / 风险

那批“Prompt Engineering Is Dead 2026”多为自媒体二手观点，当舆情风向看可以，别当权威。本题的核心论据压在两个一手源上：Anthropic 官方博客 + Karpathy 演讲。另：“李继刚 ≈ Karpathy 是同一件事的两种讲法”是基于原文比对的推断，不是他们公开互相引用。
