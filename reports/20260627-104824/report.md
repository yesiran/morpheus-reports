# 李继刚的「AMV」到底是什么 —— 一份钉死词源、再钻到底的研究

> 【墨菲斯】研究报告 · 2026-06-27
> 派出五位专家、各认领一题、并行独立钻;主 agent 收拢自评判后,用「讲清楚」重讲成此篇。

---

## 先把最重的一块给你(总判断)

你让我去全网查"李继刚说的 AMV 到底是什么"。五路专家把他的即刻、X、公众号、个人站、GitHub(29 个仓库)、IF2025 极客公园演讲、PEC 提示词大会逐字稿、2025–2026 全部能搜到的长播客,逐一啃过——**结论先甩给你:李继刚本人,从没造过"AMV"这个词。** 它在他任何一处一手内容里,一次都没出现。

这不是"没搜到",是"搜遍他核心一手内容后确认不存在"。所以这趟最该先省下的一刀是:**别再花力气去理解一个他没说过的三字母缩写。**

但故事没完,反而这里才开始有意思——因为我们在搜的过程里,撞上了一个跟 AMV **又撞音又撞义**的真东西,而它正好戳中你真正想问的:**他这套提示词哲学,是真洞见还是玄学包装?你这老手该不该信、能不能用、值不值得长期押?**

一句话把全篇压给你:**"AMV"是个误传的壳;壳底下那台真机器,是李继刚整套"提示词不是教模型、而是唤醒模型"的世界观——它偏真洞见、不是换皮;它的"术"会随模型变强而贬值,它的"道"会随模型变强而增值;而它的"道"恰好是你做京小贝、搭 Morpheus 的看家本事换了个名字。所以:下注它的内核,把它的招式当耗材。**

下面五刀,一刀一刀拆给你看。

## 第一刀 · 那"AMV"到底是怎么来的?

如果他没说过 AMV,你怎么会"听说"李继刚说过 AMV?这才是第一个该解开的疑问。

先看一个搜索引擎会出卖真伪的细节:**一个真实存在的概念,搜它会返回"窄而一致"的语料;而"AMV"一搜,返回的是一堆毫不相干的东西**——动漫音乐视频(Anime Music Video)、一种视频格式、制药业的分析方法验证、装甲车、甚至一家法国保险公司。这种"四处发散、没有一条挂得上提示词"的反应,正是"这个词在这个语境里根本没有语料"的典型信号。不是冷门,是不存在。

那真身是什么?最贴的一个,藏在他 2026 年 3 月那期跟孟岩的长播客《E45 孟岩对话李继刚:人何以自处》里。他在里头反复讲一句话:

> "我们同时活在三个世界里:**原子世界、比特世界、向量世界。**"

- **原子世界(Atom)**:你身体所在的物理现实,稀缺的是"在场";
- **比特世界(Bit)**:互联网,空间被抹平了,稀缺的是"注意力";
- **向量世界(Vector)**:AI 世界,万物被压成高维坐标,连时间都被抹平。

这三个词的英文首字母是 **A-B-V**。你看:**头尾的 A 和 V,跟"AMV"严丝合缝,只有中间那个"比特/Bit"被记成了 M。** 而 M 的来源也有着落——他另有一套常讲的框架:"影响提示词效果的三要素 = **模型(Model)/ 任务 / 提示词**"。听的人极可能把"模型 Model"的 M,和"三个世界"串了台。

所以最可信的判断是:**你听到的"李继刚 AMV",真身是他的"三个世界"(原子/比特/向量,ABV);A 对、V 对,M 是从他"模型 Model"那套错位串过来的。** 他本人从没给"三个世界"盖过任何字母缩写——ABV 也好、AMV 也好,都是后人脑补的壳。

> **这一刀的判断:** AMV = 查无此物;最可能是李继刚"三个世界(原子/比特/向量)"框架在口耳/语音转写中被串成的误记。证据强度:中高。
> **一手出处:** 播客《E45 孟岩对话李继刚》2026-03-03,官方逐字稿 `youzhiyouxing.cn/n/materials/2141`;单集 `xiaoyuzhoufm.com/episode/69a64629de29766da93331ec`。逐字稿全文出现 "Vector"、"Model",**未出现 "AMV" 与 "ABV"**。
> **唯一没封死的缺口:** 他即刻/X 的原始帖子流,这次环境下抓不到(登录墙 + 本机浏览器桥没连上)。所以无法 100% 排除他在某条没被索引/已删的单帖里临场手写过 AMV。**若你手上有 AMV 的原始截图/链接,给我,我能一步钉死或证伪。**

到这,词源这块地基算交底了。但你真正要的从来不是这三个字母——你要的是**它底下那台机器**。下面四刀,就当"AMV"= 李继刚这套提示词世界观来打(这是本案最大的承重推断,末尾会再诚实标一次)。

## 第二刀 · 剥开壳,它是台什么机器?

把那层术语外壳剥掉,你第一个会问:这玩意儿到底是"一个写法/技法",还是"一套解释"?——这俩是天差地别的两种东西。技法是螺丝刀(告诉你第一行怎么落笔),解释是图纸(告诉你为什么这么拧会松)。

答案是:**它是图纸,不是螺丝刀。** 李继刚整套东西,核心不是"教你怎么写提示词",而是回答一个更底层的问题——**"为什么一句话,能在模型里炸开成一整套行为?"**

要看清这一点,先把他那张"机器图纸"摆出来(全部有他原话坐实):

- **表达三元:本意 → 文意 → 解意。** 你心里的想法是"本意",写成的符号(提示词)是"文意",模型读成的东西是"解意"。任何一环错位,就是误解的源头。
- **效果三因素:模型 > 任务 > 提示词。** 决定输出好坏,模型排第一、任务第二,提示词只排第三——它之所以被你天天盯着抠,只是因为它是这三样里**唯一你能直接动手调**的那一环。
- **最有名的那个画面:潜空间里"点亮星星"。** 他原话:"屋子是向量空间,星星是 embedding 之后的词或概念。我通过喊星星的名字,能把那根星星点亮。"——点亮几颗、连成星座,模型就懂了。

把这三样拼起来,你就拿到了他整套世界观的内核,也是他跟所有人最不一样的那一刀:**好提示词不是"教"模型做事,而是"唤醒"模型——用最少的符号,精准点亮它潜空间里本就存在、只是默认没被走到的那片能力。**(原话:"人类的提示词要能唤醒模型与之『共振』""让模型不按既定的默认路径输出"。)

那它瞄准的那个**卡点**是什么?就是你我都撞过的那堵墙:**"我明明写得清清楚楚、明明很对,模型却不照做、跑偏。"** 李继刚给的诊断是反直觉的——病根通常**不在"你指令下得不够细"**,而在两处:① 你自己的**本意**本来就模糊(他说"答案不在外部,在内在认知深度");② 你以为你在"教"模型(往里塞越来越多的字),可机制上你只是在屋子里**点星星**,塞得越多越乱,反而点不亮你要的那个星座。

> **这一刀的判断:** AMV(=他这套)的本质是**底层机制解释**,不是可操作技法、也不是一次思想转向——它是把他"表达三元 + 效果三因素 + 点亮星星"几套东西**再压一次的内核封装**,在他思想谱系里站在"核心内核"那一格。它瞄准的卡点:**"写得对却不照做"——病根是意图没压清 / 点错了星,不是字数不够。**
> **出处:** 访谈《从哲学层面与大模型对话》`cnblogs.com/fanzhidongyzby/p/18552793/prompt`;《提示词的道与术》;知乎《当我们说"提示词"时到底在说什么》`zhuanlan.zhihu.com/p/15661946176`。

## 第三刀 · 对你这 prompt 老手,它到底新在哪?(红队压测)

这一刀最该狠,因为你是内行——最该攻的,恰恰是你太顺手的那套"什么是好提示词"的默认框架(结构化、角色设定、给例子、思维链)。我让一位专家当"红队",默认怀疑它是包装,逼它拿出"老框架解释不了、它能"的地方;拿不出就判它换皮。

红队的结论是:**偏真洞见的中间态,不是纯换皮,也不是纯营销。** 关键就一句——**他换了"操作对象"。**

看这张对照表(第一列用他**真实可考的方法**,因为字面 AMV 没有实体可压):

| 维度 | 主流框架(CO-STAR / RTF / CRISPE / CoT) | 你的默认直觉 | 李继刚真实在做的 | 真增量 / 还是换皮 |
|---|---|---|---|---|
| **操作对象** | 我**对任务的描述**(把背景切成栏位填进去) | 角色+例子+思维链(本质也是填槽) | 模型**潜空间里已有的概念坐标**(选能点亮一整条脉络的"本质词") | **真增量**:框架在黑箱外面排输入,他在赌黑箱内部有结构、可定位 |
| **核心动作** | **加法**(背景写越全越好) | 写清楚、给够上下文 | **减法**(压到只剩那个本质词) | **方向相反**——这是老框架里没有的动作 |
| **可操作性** | 高,可抄模板(填空即可) | 高(你本来就会) | **低,吃天赋,几乎没法教**(他自己只能说"多读多思,各自悟道") | 这是他的**退步面**:抓手弱、难复制 |
| **命名** | 英文缩写(CO-STAR / RTF) | 拿来即用 | **汉字三字诀**(信/达/雅、本意/文意/解意、译境、思想精炼师) | **反证**:他从不用英文三字母给东西命名——"AMV"在风格上就不像他的 |

读这张表,你要拿走的判别口诀就一句:

> **凡他给了"换个操作对象"的具体动作(去操作潜空间、而不是描述任务),算真增量;凡他只给了一个更美的比喻("点亮星星""共振""道")而没告诉你下一步该写什么,算包装。**

按这把尺子切:真的那半,是 CO-STAR/RTF 解释不了也做不到的(那些框架默认模型是黑箱,只管把输入排整齐);玄的那半,是"点星星/共振/道"——它们是**对机制的诗化描述,不是可照做的步骤**。这正是最容易"把真洞见当玄学错过"、也最容易"把营销当洞见误信"的地方。把两半切开,你就不会两头踩坑。

> **这一刀的判断:** AMV(=他这套)相对你已有框架的**真实增量 = 把操作对象从"描述任务"挪到"操作模型潜空间里的概念坐标",方向从加法翻成减法**;它**不是**主流框架的换皮。整体性质:**偏真洞见的中间态**,真在"换了操作对象",虚在"用诗化比喻冒充操作步骤"。
> **出处:** CO-STAR 出自新加坡 GovTech(Sheila Teo 打榜文);李继刚真实作品(译境、思想精炼师 v1.0)`x.com/lijigang_com`、`github.com/lijigang/write-prompt`。

## 第四刀 · 这东西,能上你的手吗?(京小贝 / 你的 skill)

判断完"真不真",才轮到你最够得着的那只手:**我能不能直接拿它改我的 skill、改京小贝的提示词?**

答案:**部分可借鉴——其中一半能直接落地,另一半只能当心法。** 而且这里有个**反向陷阱**,专门给你这种老手挖的,后面会点。

先把这套**切成两半**:

**【能直接照做的动作】**(真能改一行字的)
1. **动手前先逼问"本意"**:我到底想让模型变成谁、产出什么质感?这句不写清,prompt 没有锚。
2. **用"定义",别用"描述"**:能用一个一锤定音的身份词框死的,就别写一长串行为说明——模型对"定义词"的解压,远大于对"描述句"的(他原话:"尽量选用词汇的定义而非描述")。
3. **做减法,删冗余指令**:每加一条规则前先问"这是不是在教模型它本来就会的事(理解情绪、说人话、分点)?"是,就删。
4. **找"本质词"当杠杆**:把一段啰嗦要求,压成一个能"一词点亮一片"的核心词。
5. **认清提示词只排第三**:别把力气全砸在抠字眼上——先确认模型选对了(你已经在做:全链路最强档)、任务切对了。

**【没法照做的空话】**(听着对,但改不了一行字)
- "点亮星星 / 在潜空间点星座"——好用的**心智图景**,帮你*理解*为什么定义词强,但它不告诉你*该写哪个词*。当解释收下,别当方法。
- "唤醒 / 共振 / 道"——方向对,但"怎么算唤醒成功"无法验证、无法照做。
- "汉字三字诀美学""Lisp 风格写 prompt"——那是他的**个人品味和表达载体**,不是效果来源。你照搬只会得到一个"像他、但不像京小贝"的东西;把 skill 改成 Lisp 更是纯仪式,团队还没法维护。

**一个真刀真枪的 before/after**(拿京小贝"用户问『我这只基金还能拿吗』"演示,after 是用他内核改的):

*Before(传统堆指令式):*
```
角色:你是一位专业、严谨、温暖的金融投资顾问助手。
当用户问"还能不能持有"时,严格按步骤:1.先安抚情绪 2.检索近1月/3月/1年涨跌
3.分析短中长三维度 4.给持有建议 5.用通俗语言 6.附风险提示。
格式:分点,每点≤3行,总字数300-500。
```
毛病:全是"教模型它本来就会的事"(安抚、通俗、分点),还把详略写死成模板,反而压住了模型自己的判断。

*After(定义而非描述 + 减法 + 本质词):*
```
你是用户的投资思考伙伴,不是顾问——你不替他做买卖决策,
你帮他看清:他这只基金靠一个什么样的"物理硬限制"在涨跌,
而这个硬限制现在卡在哪。

"还能拿吗" = 用户在情绪里。先一句点破他真正卡在哪,
再给"判断 + 紧挨判断的那个事实",最后留一个他正想问的下一步。
详略跟着这只基金自己的逻辑走,别凑三段式。
```
差在哪:用"投资思考伙伴 / 看清物理硬限制"这个**定义**,替掉了"专业严谨温暖"那串**描述**;删了模型本就会的步骤;"物理硬限制"是**本质词**,一词点亮模型对供需/周期的整片理解;详略还给了模型。

**那个反向陷阱(最关键):** 别因为这套漂亮就**整个倒向李继刚的极简风**。他的活计(汉语新解、译境)是**通用创意**,点的星星是模型预训练里现成就有的,所以越压越灵;而**京小贝是生产级 + 强私有领域**——它的护城河恰恰在那些模型不自带的东西:京东金融的回复口味、合规红线、领域常识。**这部分潜空间里没有现成的星星,只能靠你灌示范("得其真意忘其言语"那几个案例),删不得。** 所以正确姿势是:**用他的减法刀,砍掉"教模型它本来就会的事"的废指令;但保留、甚至加厚你的私有示范。**

> **这一刀的判断:** 对你**部分可借鉴**——减法刀法(定义而非描述、删冗余、找本质词、先逼问本意)**可直接上手改你的 skill**;但"点星星/共振/Lisp 美学"是心法不是方法,且**生产级强领域场景不能照搬极简**:减冗余指令,保私有示范。
> **出处:** 少数派 `go-post.sspai.com/post/108114`;博客园访谈;`github.com/lijigang/write-prompt`。(before/after 为演示构造。)

## 第五刀 · 该不该长期押?(给你长期主义那只手)

你是看二阶、看长期的人。所以最后一问必须升一层:**模型越来越强,这套东西会更值钱,还是被强模型自己消化掉、贬值?**

这一题的胜负手,是**把它劈成两层**——劈开之后,两层的命运正好相反:

| | 是什么 | 模型变强后 | 谁在背书 |
|---|---|---|---|
| **术(技巧层)** | 具体话术、模板、咒语、"扮演专家"那类花活 | **贬值** | 连 Anthropic 官方都说"模型越强,越要少规定"(smarter models require less prescriptive engineering);"let's think step by step"这类老咒语在 2026 前沿模型上已从有用变没用甚至有害;模型还会自己写提示词(meta-prompting) |
| **道(认知/对齐层)** | 把脑子里那团模糊"本意"压成精准符号、对齐给一个智能体的能力 | **增值** | Karpathy:"理解你要造什么、为什么造,是一种**不可压缩**的人类技能","intent specification 是新的编程";模型越强,瓶颈越从"它会不会做"挪到"你想没想清楚" |

那李继刚这套,重心压在哪一层?——**压在"道"上。** 这是能不能下注的关键,我让专家回他原文核了:

- 他的**本意→文意→解意**,讲的根本不是话术,是"把人脑海里的想法精准交给模型理解"——这跟 Karpathy 说的"intent specification"**是同一件事**,只是一个用中文哲学讲、一个用工程黑话讲。
- 更狠的是,**他自己早就预判了模型会变强**,原话:"未来大模型知道的越来越多(他叫'X 轴下移'),那么对人这个个体来说,如何丰富自身的认知边界就越重要。"——**他亲手把价值的钉子,从"提示词技巧"钉到了"人的认知"上。**

一句话:**他那套会贬值的外壳(具体话术),他自己也不靠;他真正押注的内核(把意图压准、唤醒而非教导、人的认知边界是上限),正好站在"增值"这一边。**

落到你身上,用段永平那只手算这笔账:

1. **下注内核,别下注外壳。** 模板/咒语当**易耗品**(每代模型作废一批,2026 已经在作废);"本意/文意/解意 + 唤醒而非教导 + 减法不是加法"当**长期资产**。模型越强,会用模型的人不稀缺,**能把自己意图压清楚的人才稀缺**。
