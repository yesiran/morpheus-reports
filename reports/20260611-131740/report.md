# 五个缩写,一棵树 —— PPO / DPO / GRPO / DPPO / DRPO 全图谱

**总判断(只读这一段也带得走):** 你列的五个词不是五个并列的算法,是同一个问题在不同预算下长出的一棵家族树。那个问题是:预训练只教会模型『猜下一个词』,没教会它『什么样的回答算好』——这族算法全是往模型里灌『好/坏信号』的不同方案,分岔只在三个旋钮:**信号从哪来**(人类口味还是机器判对错)、**让不让模型真试错**(在线生成还是离线模仿)、**养不养得起裁判班子**(打分和估值的那几个附属模型)。

先剧透一个意外:DRPO 和 DPPO 这两个词,我们一度怀疑是你语音输入听岔了——查下来是真算法,而且其中一篇是你提问前三天刚挂上 arXiv 的最新论文。你刷到的不是冷门旁支,是前沿最新鲜的一页,新到我们差点把它当成你的口误。

下面顺着这棵树从根讲到梢,最后折成一张你带得走的判断卡。

---

## 一、这族算法到底在解决什么问题(地基)

先放一个反常识的硬数字。2022 年初 OpenAI 公布过一个结果:一个 **13 亿**参数的小模型,在人类盲评里赢了 **1750 亿**参数的 GPT-3——参数差一百倍,人却更喜欢小的那个。两个模型预训练完全同源,差别只在中间多了一道工序。这道工序就是「后训练」,而这个结果给它标了价:**值一百倍参数。**

为什么预训练留了这么大的洞?预训练的目标只有一个——猜下一个词,让输出"像互联网语料"。你问早年的 GPT-3"怎么给六岁孩子解释登月",它很可能续写出一串类似的问题——因为互联网上,问题后面常常跟着更多问题。它不笨,是**没人告诉过它"回答"比"续写"好**。"什么样的输出算好"这个信号,预训练里压根不存在。

最朴素的补法当然是:雇人写标准答案,让模型照着抄——这就是 **SFT**(监督微调,人话=照范文抄)。有效,能教会格式和"助手姿态",但抄范文这个机制本身有两块结构性天花板,堆再多数据也填不平:

- **它表达不了"A 比 B 好"。** SFT 的信号只有"照这条写",没有比较、没有负分。可"好"大多是相对的:两版回答哪个更清楚、哪个语气更妥,人一眼比得出来,却写不出唯一标准答案。比较比示范便宜,信息还更密。
- **更隐蔽的一条:SFT 在机制上教模型一本正经地胡说。** 写示范的人按"自己知道的"写答案;如果模型权重里没有这条知识,这条数据教给它的就不是知识本身,而是"碰到这类问题,要自信地编一个"。这是 PPO 作者、ChatGPT 负责人 Schulman 公开讲过的机制,在"照抄范文"的框架内无解。

这两个缺口,就是整族算法的出生地。解法的共同思路:别让模型抄别人的,**让它自己生成回答、给回答打分、按分数调整自己**——相对偏好天然可表达,负分天然存在,而且被罚的回答出自模型本人,胡说终于罚得到胡说者。

往下走之前,把行话一次焊牢(往后全用人话称呼):

| 行话 | 人话 |
|---|---|
| policy(策略) | 正在被训的模型本体——"学生",负责出招写回答 |
| reward(奖励) | 给一条回答打的分,就是一个数字 |
| reward model(奖励模型) | 学会了人类口味的打分器——"裁判",替人 24 小时打分 |
| critic(价值模型) | 估"从这个字往后还能挣多少分"的"会计",把总分摊到每个字头上 |
| reference model(参照模型) | 出厂版模型,冻结不动——"参照物",拴着学生别训跑偏 |

## 二、PPO:全套正规军,强,但有两个死穴

**判断先行:PPO 的本质是「在线试错 + 裁判打分 + 小步快走」。它的两个死穴——贵、娇气——就是后面所有变体的出生证:每个后来者都在锯它身上的某根贵零件。**

ChatGPT 当年用的这台机器,一次训练要在显卡里同时塞**四个**大模型。教一个模型说话,为什么要供四尊佛?

**学生**(被训的模型)现场写答案,**裁判**(打分器)给分——这是"在线试错"的最小配置。但裁判有个毛病:一段五百字的回答写完才给一个总分,到底哪句加了分、哪句减了分?没人知道。于是要请**会计**(critic):逐字估"从这往后还能挣多少分",功劳才摊得到每个字头上。麻烦在于,会计通常和学生一个量级,还得**和学生同步训练**——而它核算的对象(学生的水平)本身每天在变,等于在晃动的秤上称重。这是 PPO 训练里公认最难伺候的一环。

裁判还能被骗。学生很快会发现裁判的偏好漏洞:裁判偏爱长回答,它就学会啰嗦;OpenAI 自己的实验里,练过头的模型产出裁判打高分、人看着是烂文的"病态摘要"。这叫 **reward hacking**(人话=学会刷分,而不是变好)。所以要第四个模型——**参照物**(出厂版,冻结),配 KL 罚款拴住学生:每偏离出厂性格一分,扣一分。

PPO 名字里的"近端"(Proximal)是它的保命招:每次更新只挪一小步(把更新幅度硬剪在小区间内),因为长文本上的收益估计噪声极大,一步迈大,训练当场崩。小步快走是 PPO 对自己娇气体质的自我治疗——治标不治本。

账算下来,两个死穴清清楚楚:

- **贵**:70B 的模型,光四份权重就 560GB 显存起步,还没算训练时的其他开销。四件套里裁判、参照物谁都躲不掉,唯独**会计是 PPO 自己加的添头**——一整个大模型,只为估分。
- **娇气**:超参敏感是表症,病根是 Goodhart 定律——"指标一旦成为目标,就不再是好指标"。OpenAI 量化过:对裁判分数优化过头,真实质量先升后降,这条曲线不靠运气、靠规律。

记住这两个死穴,后面的演化史就是一张藏宝图。

## 三、DPO:干脆不打仗的捷径

**判断先行:DPO 用一个数学恒等式把「先训裁判、再让学生试错」两步并成一步,训练成本降到和 SFT 一个量级;代价是它学的永远是固定数据集里的"口味快照",不能边试边学,上限钉死在标注者已经写出来的答案上。**

DPO 论文(2023)的标题就把魔术说破了:**"Your Language Model is Secretly a Reward Model"——你的语言模型,偷偷就是个打分器。** 人话版:RLHF 要解的那道题("在别跑偏太远的前提下,让裁判分最高")恰好有个解析解——裁判给某条回答打多少分,**等价于**新模型比出厂版把这条回答的概率抬高了多少倍。既然分数能从概率变化里反推出来,那就不要裁判了:直接拿"A 比 B 好"的对比数据,要求模型抬高 A 的概率、压低 B 的概率——抬压的幅度本身就隐含了一个打分器。裁判、会计、在线试错、PPO 的全部工程地狱,一并省掉。

便宜到这个程度,代价在哪?三个,长在同一条根上:

- **离线。** DPO 从没让模型自己生成回答再拿反馈,它学的是数据集那份口味快照。训练本身在改变模型,模型的输出和对比数据的分布必然越错越开——之后它等于在批改别人的作业。对照实验(ICML 2024)里,同等条件 PPO 全面胜过 DPO,尤其在代码这种能验对错的任务上。
- **压坏不抬好。** DPO 的目标只看 A、B 的相对差距,把 B 压得更狠也算"进步"。后续研究(ICLR 2025)实证了更糟的版本:训练中连"好回答"的概率也经常在掉,概率质量漏给了数据外的回答。
- **上限是数据集。** 真试错能探索出训练数据里没有的解法(R1 的"aha moment"就是探索出来的);DPO 永远只能逼近标注者已经见过的好。

那条"2023-24 人人用 DPO,这两年前沿又回流真 RL"的流行叙事,我们拿四家公开技术报告验了——**半真半假,真实格局不是"回流",是"分工定型"**:

| 模型 | 实际配方 |
|---|---|
| Llama 3(2024) | SFT+拒绝采样+DPO 六轮,明确弃用 PPO(自述:在线 RL 更不稳、更难扩展)——DPO 路线的顶峰 |
| Qwen2.5(2024)→ Qwen3(2025) | Qwen2.5 是分工活标本:DPO 调口味(离线)→ GRPO 长能力(在线);到 Qwen3,DPO 从主管线消失 |
| DeepSeek V3 / R1 | SFT + GRPO,技术报告全程未见 DPO |
| Kimi k1.5 / K2 | SFT + 大规模在线 RL,报告未见 DPO |

所以分界线是一句人话:**调口味,用 DPO;长能力,上真 RL。** 你以后听到"我们用 DPO 训的",该听出的隐含信息是:这个模型的口味被校准过,但能力天花板还是 SFT 那一层——**它没有自己试错过。**

## 四、GRPO:留着打仗,裁掉会计——R1 一代的主角

**判断先行:GRPO 砍掉的是 PPO 身上最贵的零件——会计(价值模型),用"同一道题答一组、组内比平均"顶替估值;它恰好撞上"答案可自动判对错"的时代,判分免费 + 会计开除,大规模推理强化学习从养不起变成养得起——这就是 R1 的配方,也是 2025-26 这波 reasoning 模型的公共配方。**

回看 PPO 的账本:会计最贵(和学生一个量级、还要同步训练),而它的活在长推理上本质干不好——几千字的解题过程,最后只有一个"对/错",中间每一步功过怎么摊?DeepSeekMath 论文(2024.02)的刀就砍在这:**会计直接开除**。替代方案朴素到近乎耍赖:同一道题,让模型一口气生成一组答案(比如 8 个),全部交卷打分,**组内平均分就是基准线**——比平均好的,生成它的每一步加分;比平均差的,每一步减分。用"同组同学的平均水平"顶替了"会计的专业估值"。不优雅,但便宜,四件套变三件套。

但这一刀单独使不出威力,它需要一个搭档:**可验证奖励**(RLVR,人话=答案对错由机器自动判,不用人评)。数学题有标准答案、代码有测试用例,一行规则代码判对错——判一亿次不要钱,而且**骗不了**:模型再花言巧语,糊弄不了一个只认最终答案的判分脚本(R1 论文自述,他们弃用神经网络裁判,正是因为大规模训练里它会被刷分)。于是闭环成立:裁判免费、会计开除,大规模 RL 的成本只剩"让模型多答几遍"——生成是推理算力,便宜、好并行。**养不起的游戏,变成了养得起的游戏。**

为什么发明它的偏偏是 DeepSeek?有据的部分:GRPO 论文自述动机就是省训练资源;梁文锋在《暗涌》专访里说过"我们的问题从来不是钱,而是高端芯片被禁运"。"算力紧张直接逼出 GRPO"这根因果连线没有官方原文明说,属于动机与产出高度吻合的合理推断——但方向上,这确实是一项被约束逼出来的发明。

反过来也就看清了它的边界:GRPO 把一个总分摊给整条回答,没有会计帮它细算,所以**总分必须绝对可靠**——离开"机器能判对错"的题(写作、聊天这种口味题),只能请回会被刷分的神经裁判,这套配方立刻失灵。所以它至今主要统治数学和代码。它自己的毛病也记一条:**长度偏置**——答错时答得越长、每个字挨的罚越轻,模型学会用啰嗦稀释惩罚,回答越训越长。这个毛病,正好是下一节两个新词所在的那条支线在修的墙。

## 五、DRPO 和 DPPO:不是你听岔,是你刷到了三天前的前沿

先说实话:这两个词不像前三个人人皆知,文献里 DRPO 至少撞名五次、DPPO 至少四次,单拎哪个出来都是悬案。我们最初的怀疑是你语音输入串了音(把字节的 DAPO 或者"Dr. GRPO"听岔)。查完发现不是,而且答案比听岔有意思。

破案的钥匙是你把它俩**放在同一句话里**问。因为恰好存在一篇 2026 年 6 月 8 日——你提问前三天——刚挂上 arXiv 的论文,它提出的算法就叫 **DRPO**(Divergence Regularized Policy Optimization),而它开篇批判并改进的上一代就叫 **DPPO**(Divergence Proximal Policy Optimization,同系 2026 年 2 月的工作,作者正是写 Dr. GRPO 的 Sea AI Lab/新加坡国立一系)。两个生僻缩写恰好凑成一篇新论文的主角和前作——用"你刷到了这篇论文或它的讨论"一个假设就全解释了,比"两次独立听岔"的概率高得多。

它们改的是什么?一句人话:**PPO 控制步子用的是把粗尺子(看单个词的概率比值,超界就剪),DPPO 说几十万词表上这把尺子量不准、换了把准尺(直接估整个策略偏了多远),DRPO 再把规矩从"超了就罚站"改成"超多少拉回多少"。** 它们和 DAPO(字节,把 GRPO 训稳的工程化改良)、Dr. GRPO(修长度偏置)是并排的兄弟支线,都在修 GRPO 时代的同一面墙——这棵树最新的枝杈,全长在 GRPO 上,这本身就告诉你现在的主干是谁。

诚实标注:"你刷到的就是那篇"是基于共现+时间吻合的最大似然推断,钉不到实锤;若你的信息源其实更早,那 DPPO 仍指 2 月那篇,DRPO 则回退为"Dr. GRPO 听岔"最可能。两篇 2026 论文都太新,没有同行评审,这里只钉"是什么",不背书"好不好"。

顺手送你一个带得走的元判断:**这个领域缩写撞名是常态(DRPO 一个壳里装着五个算法),听到生僻缩写,第一反应不是假装认识,是问出处——哪篇论文、哪个组、哪个月,三个坐标一钉,壳里是谁立刻现形。**

## 六、折成一张判断卡

以后听到"我们用 X 算法做了后训练",**别问算法名,问三件事**:

**① 奖励信号从哪来?**
- "人类标注偏好/训了奖励模型" → 经典路线,上限是标注员口味。追问:怎么防刷分?答不上来打折。
- "可验证奖励,代码跑测试、数学对答案" → 信号最硬,能力提升最真。但追问:你的业务问题真在这个范围吗?(金融场景多数不在。)
- "评分细则(rubric)/模型自评" → 2025 起的前沿玩法,把 RL 扩展到没有标准答案的领域。追问:怎么防模型骗过自己养的裁判?

**② 在线真试错,还是离线模仿?**
- "DPO/离线数据" → 便宜稳,调口味;别指望能力突破。再追问数据来源:偏好对若是蒸馏别家模型,上限就是别人家的水平。
- "在线 RL(PPO/GRPO 系)" → 天花板高但烧钱。追问生成规模和训练量——投入量直接暴露这事做得是真是假。

**③ 养没养裁判班子,裁判会不会被骗?**
- "拿现成大模型当裁判" → 最省事也最易被钻空子,默认成色普通。
- "专门训的奖励模型 + 独立于训练信号的评估集" → 正规军。用裁判自己出题自己阅卷的,是红旗。
- "执行环境/规则直接判" → 最硬的裁判,但要问领域覆盖。

三问其实是一件事的三面:**这个模型被什么信号塑造,那个信号本身可不可靠。**

**30 秒族谱(讲给别人听的版本):** 预训练只教模型接话,没教什么算好,这族算法全是往模型里灌"好坏信号"的方案——PPO 是全套正规军,裁判会计参照物全配,强但贵且娇气,ChatGPT 用它起家;DPO 干脆不打仗,直接拿"A 比 B 好"的数据照着学,便宜但天花板低;GRPO 留着打仗、裁掉会计,一题答八遍组内排名,撞上"机器能判对错"的时代,靠 DeepSeek-R1 成了主流;DAPO、Dr. GRPO、DPPO、DRPO 这些是给 GRPO 时代修毛病的补丁。

**往后 12 个月竖耳朵的词(只列有实据的):**
- **Agentic RL**(人话=在真实环境里干活拿奖励):不再对着题库刷题,而是在真实代码库、工具链里完成任务,以"任务做没做成"当奖励。Qwen3-Coder 用约两万个并行执行环境训练,Meta 的 SWE-RL 拿 GitHub 真实提交当奖励来源——这是 2026 年各家 coding/agent 模型的共同打法。
- **Rubric reward**(人话=评分细则当裁判):把"可验证"的纪律带进没有标准答案的领域。Kimi K2 技术报告明确写了可验证奖励+自评细则双轨;Scale AI 的论文在医疗问答上比"大模型当裁判"提升 31%。**对金融场景,这是最值得盯的一个**——金融回复恰恰是"没有唯一标准答案、但有好坏标准"的领域。
- **PRM/过程奖励**(人话=给解题的每一步打分),**打折听**:研究很热,但 DeepSeek-R1 论文公开把它列为"不成功的尝试"——模型学会了骗过步骤裁判。听到就追问:是训练时当奖励(存疑),还是推理时挑答案(成熟)?

**对你这个角色,真正值得持续盯的只有一个变量:奖励信号的来源与可靠性——不是算法名。** PPO 到 GRPO 到 DRPO,换的全是输水的管道,管道工艺三年三代;决定水质的始终是源头。具体到你的位置:**谁能把"金融上什么算好回答"变成机器可执行的可靠奖励(合规规则可验证、专业判断细则化),谁的后训练才有真成色。** 供应商说"我们用 GRPO 训的"等于什么都没说;说得清奖励怎么来、刷分怎么防、评估集独不独立,才值得继续谈。

## 收束

回到开头那个问题:五个缩写是什么意思?现在它们都挂在树上了——同一个"怎么把好坏信号灌进模型"的问题,PPO 给了全套正规军的答案,DPO 给了不打仗的捷径,GRPO 裁掉会计赶上了机器判分免费的时代,DPPO/DRPO 是这棵树最新枝杈上、三天前刚冒头的嫩芽。下次再冒出新缩写,你已经不需要这份报告了:先问出处(哪篇论文哪个组哪个月),再问它换的是**管道**还是**裁判**——换管道的可以略过,换裁判的才值得开会。

## 还没压实的(诚实清单)

- **DRPO/DPPO 的真身判断是最大似然推断**(两词共现+论文时间与提问时间吻合),不是实锤;若你的信息源早于 6 月 8 日,DRPO 的最可能真身回退为"Dr. GRPO 听岔"。两篇 2026 论文均无同行评审。
- **"算力紧张逼出 GRPO"的因果连线是推断**:论文只自述"省训练资源",梁文锋只承认"芯片禁运是最大约束",两者之间没有官方文本明说。
- **闭源前沿(GPT/Gemini/Claude)的后训练配方不公开**,"能力增长靠在线 RL"对它们是基于公开范式的推断;"DeepSeek/Kimi 全程无 DPO"基于技术报告未提及,不能排除内部小规模使用。
- 70B×4 份权重 560GB 是算术下限,实际占用更高;Qwen3-Coder"两万并行环境"出自官方发布材料,经二次来源确认,未核对原始报告原文。
